# Resource Booking System

A complete, production-ready RESTful Resource Booking System built with Java 17+, Spring Boot 3.x, Spring Data JPA, Spring Security (Stateless JWT), and MySQL.

## Tech Stack
- Java 17+
- Spring Boot 3.x
- Spring Data JPA
- Spring Security (Stateless JWT)
- MySQL
- Swagger/OpenAPI

## Features
- Role-Based Access Control (Admin, User)
- Stateless JWT Authentication
- Resource Management
- Reservation System with overlapping validations
- Database Pagination and Filtering
